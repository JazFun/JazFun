## Session Description (For Promotion)

**You've got ChatGPT working. Maybe Claude too. But let's be honest: your firm isn't actually running on AI.**

Your team still does things manually. Sarah uses prompts one way, Mike uses them differently. You're still the bottleneck. If you got hit by a bus tomorrow, all those "AI wins" would fall apart.

**That's not an operating system. That's isolated hacks that depend on you.**

In this 60-minute session, you'll discover the 3-Tier AI Operating System Architecture that transforms scattered ChatGPT tricks into unified firm intelligence. You'll watch three live builds that show exactly how to move from task-level tools to workflow-level systems to firm-wide operating infrastructure.

**You'll leave with:**
- The 3-Tier Framework (poster-sized, screenshot-ready)
- The Operating System Decision Matrix (know what belongs in your system)
- The Verification Framework Template (stay in control of AI outputs)
- Copy-paste prompts for each build
- A clear path to systematizing YOUR workflows in the upcoming bootcamp

**This isn't another ChatGPT tips session. This is architecture.**

## Learning Objectives

By the end of this session, participants will be able to:

1. **Identify** which tier of AI operating system they're currently operating in and what's holding them back from scaling
2. **Apply** the 3-Tier Architecture Framework to evaluate and categorize their existing AI workflows
3. **Build** a Claude Operations Brain project that holds firm processes and delivers consistent guidance
4. **Implement** a verification layer that ensures AI outputs meet professional standards before team execution

## The Three Builds

### Build #1: Task Layer - Bookkeeper Buddy (5 minutes)
**What it is:** A learning/mentorship GPT for junior team members
**Purpose:** Standardize institutional knowledge across the firm
**Demo:** Junior asks question → Gets framework-based answer → Team learning is consistent

### Build #2: Workflow Layer - Claude Operations Brain (8 minutes)
**What it is:** Claude Project holding SOPs, processes, and decision rules
**Purpose:** Team executes consistently without senior bottleneck
**Demo:** Pre-built structure + live question → Claude applies YOUR firm's logic

### Build #3: System Layer - Operations Brain with Verification (12 minutes)
**What it is:** Claude Operations Brain + verification/quality control layer
**Purpose:** AI amplifies judgment, doesn't replace it
**Demo:** Claude gives guidance → Verification checklist → Team execution pathway
