### SLIDE 17: The Verification Checklist
**[DISPLAY AT: 0:41]**

**Headline:**
# The Verification Checklist

**Visual:**
Clean checklist format:

**Before ANY team member acts on Claude's guidance:**

- [ ] **Contract Alignment:** Does this comply with our engagement terms?
- [ ] **Timeline Impact:** Does this affect any deadlines?
- [ ] **Approval Required:** Does this need manager sign-off?
- [ ] **Client Communication:** What needs to be communicated?
- [ ] **Documentation:** Where does this get logged?

**Bottom Text:**
All checks pass → Execute
Any check fails → Escalate

**Speaker Notes:**

### SLIDE 18: Verification Applied
**[DISPLAY AT: 0:44]**

**Headline:**
# Applying Verification to Claude's Guidance

**Visual:**
The five checks with answers filled in for the date change scenario:

**Claude Said:** Handle client date change request

**Verification Results:**
1. Contract Alignment: Check engagement letter - may need amendment
2. Timeline Impact: Yes - 5th is tighter than 15th, assess capacity
3. Approval Required: Yes - date changes require manager approval

5. Documentation: Client file notes + workflow calendar

**Result:** Can't just say "yes" - need manager, specific communication, documentation

**Speaker Notes:**

## VISUAL DESIGN NOTES

### Color Palette Suggestions:
- **Tier 1:** Blue (task, action)
- **Tier 2:** Green (growth, workflow)
- **Tier 3:** Purple (system, sophistication)
- **Warning/Limitation:** Red/Orange
- **Success/Achievement:** Green

### Typography:
- Headlines: Bold, sans-serif
- Body: Clean, readable
- Quotes/Key points: Larger, emphasized

### Imagery:
- Avoid stock photos of robots
- Use architectural/systems imagery
- Clean diagrams over complex graphics
- Consistent iconography throughout

### Transitions:
- Simple fades or cuts
- No distracting animations
- Let content speak
