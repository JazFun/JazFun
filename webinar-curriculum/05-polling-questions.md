# Strategic Polling Questions
## The Accountant's AI Operating System Webinar

---

## Polling Strategy Overview

Polls serve three purposes in this session:
1. **Engagement** — Keep attention high in a 60-minute virtual session
2. **Self-Identification** — Help attendees see where they are (creates desire to move)
3. **Bootcamp Qualification** — Identify who's ready for next step

---

## Poll #1: Opening Engagement

**Timing:** 0:05 (During Hook)
**Purpose:** Quick engagement, set the tone
**Type:** Chat response (not formal poll)

**Prompt:**
"Quick question in the chat: Type 'CHAOS' if your AI workflows feel scattered right now. Type 'SYSTEM' if you feel like you've got it figured out."

**Follow-Up Language:**
- If mostly CHAOS: "I'm seeing a lot of chaos. That's exactly why we're here today."
- If mixed: "Interesting mix. By the end of this session, the 'chaos' folks will know exactly what 'system' looks like."
- If mostly SYSTEM: "Nice! Let's see if your system matches the architecture I'm about to show you."

**Why This Works:**
- Low barrier (just type a word)
- Creates immediate participation habit
- Names the pain without being negative

---

## Poll #2: Tier Self-Assessment

**Timing:** 0:24 (End of Framework Reveal, before builds)
**Purpose:** Self-identification, creates desire to move up tiers
**Type:** Chat response

**Prompt:**
"Type 1, 2, or 3 in the chat—which tier do you think you're currently operating in?"

**Follow-Up Language:**
- "A lot of 1s... Let's change that."
- "Some 2s in there—good. Let's talk about what Tier 3 looks like."
- "Nobody saying 3? That's honest. And that's fixable."

**Why This Works:**
- Makes the framework concrete and personal
- Most will say 1 or 2, creating aspiration
- Sets up the builds as "here's how to move up"

---

## Poll #3: Main Poll (Formal)

**Timing:** 0:52 (After all builds, before gifts)
**Purpose:** Bootcamp qualification, final engagement
**Type:** Formal poll with results shown

**Question:**
"Which tier are you currently operating in?"

**Options:**
- A) Tier 1 only (isolated ChatGPT wins, no connected systems)
- B) Tier 1 + some Tier 2 (some workflows, but not consistent)
- C) I want Tier 2-3 but don't know how to build it
- D) I'm not sure what tier I'm in

**Follow-Up Language by Result:**

**If mostly A:**
"That's where most firms are. And there's nothing wrong with Tier 1—it's valuable. The question is: do you want to stay there? The bootcamp is specifically designed to take you from Tier 1 to a working operating system."

**If mostly B:**
"You've started the jump. That's harder than staying at Tier 1. The gap now is consistency and verification—exactly what we covered in Build 3. The bootcamp helps you formalize what you've started."

**If mostly C:**
"This is the honest answer. You know what's possible, you just need the path. That's the bootcamp. We build YOUR system together, not just templates."

**If mostly D:**
"Also honest. If you're not sure, you're probably at Tier 1 with some experiments. The Decision Matrix I'm about to give you will help you figure out exactly where you are."

**Why This Works:**
- All answers lead to bootcamp as logical next step
- No "wrong" answer, reduces resistance to responding
- Creates data point for follow-up segmentation

---

## Poll #4: Verification Gap (Optional)

**Timing:** 0:48 (After Build #3, if time allows)
**Purpose:** Deepens the verification conversation, bootcamp bridge
**Type:** Formal poll

**Question:**
"What's YOUR biggest verification gap right now?"

**Options:**
- A) I don't know what to verify
- B) I have checklists but they're not consistent
- C) My team doesn't follow the verification steps
- D) I'm verifying everything myself (still the bottleneck)

**Follow-Up Language:**

**If mostly A:**
"You need a framework before you need tools. That's Day 3 of the bootcamp—we build your verification criteria together."

**If mostly B:**
"Inconsistency is an execution problem, not a knowledge problem. The operating system solves this—everyone uses the same checklist, every time."

**If mostly C:**
"Team adoption is the hardest part. The system has to be easier than NOT using it. That's what we design in the bootcamp."

**If mostly D:**
"You're still the bottleneck. The verification framework is what lets you delegate with confidence. That's the whole point of Tier 3."

**Why This Works:**
- Every answer points to a bootcamp solution
- Attendees self-identify their specific pain
- Creates urgency around solving the verification problem

## Chat Engagement Prompts (Throughout Session)

These are not formal polls but keep energy high:

| Time | Prompt | Purpose |
|------|--------|---------|
| 0:05 | "Type CHAOS or SYSTEM" | Opening engagement |
| 0:08 | "Type YES if that hits home" (after fear statement) | Emotional connection |
| 0:24 | "Type 1, 2, or 3 for your current tier" | Framework internalization |
| 0:29 | "Type RELATABLE if Bookkeeper Buddy solves a problem you have" | Build #1 validation |
| 0:37 | "Type WANT if you want an Operations Brain like this" | Build #2 desire |
| 0:47 | "Type AHA if the verification layer clicked for you" | Build #3 understanding |
| 0:56 | "Type GOT IT when you've grabbed the downloads" | Confirms engagement with materials |

That's exactly why I created the bootcamp. Not to teach you more theory, but to help you BUILD your specific system.

Before I tell you about that, let me give you something you can use RIGHT NOW..."

[Transition to Framework Gifts]

## Poll Results: What To Track

For post-webinar analysis:

1. **Tier Distribution** — What % are at each tier?
2. **"C" Responses** — These are your warmest bootcamp leads
3. **Chat Activity** — High responders are engaged prospects
4. **GOT IT Count** — Confirms template downloads

---

## Polling Platform Notes

**If using Zoom:**
- Set up polls in advance
- Keep options visible long enough to read
- Share results briefly, don't over-analyze

**If using other platforms:**
- Chat-based responses work well
- Have moderator track key responses
- Acknowledge responses verbally
