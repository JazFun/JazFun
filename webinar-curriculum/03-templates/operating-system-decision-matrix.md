# Operating System Decision Matrix
## Should This Workflow Be In Your AI Operating System?

---

## The 4-Question Test

For any workflow in your firm, answer these four questions:

| Question | Yes | No |
|----------|-----|-----|
| **1. Is it repeatable?** (Happens more than once a month) | [ ] | [ ] |
| **2. Does it touch client data or deliverables?** | [ ] | [ ] |
| **3. Is there currently a bottleneck person?** (Someone the team waits on) | [ ] | [ ] |
| **4. Does it need a verification step?** (Quality check before delivery) | [ ] | [ ] |

---

## Decision Rule

| YES Answers | Recommendation |
|-------------|----------------|
| **0-1** | Keep as ad-hoc task. Tier 1 GPT may help but don't systematize. |
| **2** | Consider for Tier 1 automation. Build a Custom GPT. |
| **3-4** | **This belongs in your operating system.** Build into Claude Project with verification. |

## Common Workflows by Tier

### Tier 1 (Task Layer) - Custom GPTs
- Email drafting and polishing
- Data formatting and cleanup
- Quick research questions
- Document summarization
- Basic calculations and explanations

### Tier 2 (Workflow Layer) - Claude Projects
- Month-end close process guidance
- Client onboarding procedures
- Quality review checklists
- Escalation decision trees
- New hire training Q&A

### Tier 3 (System Layer) - Full Operating System
- Brand voice and communications standards
- Client service protocols with verification
- HR policy guidance with approval workflows
- Financial analysis frameworks with review steps
- Operations manual with team execution paths

## Your First 48 Hours

If you identified workflows that score 3-4:

**Day 1:**
1. Document the current process (even rough notes)
2. Identify who currently holds the knowledge
3. List the verification steps that should happen

**Day 2:**
1. Create a Claude Project
2. Upload your process documentation
3. Test with 3 real questions
4. Build your verification checklist
