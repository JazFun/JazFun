# Verification Framework Template
## Quality Control Before Team Execution

---

## The Core Principle

**AI gives guidance. Verification ensures quality. Then your team executes.**

This framework sits between Claude's recommendation and team action. It's what transforms a tool into an operating system.

---

## The 5-Point Verification Checklist

Before ANY team member acts on AI-generated guidance, they answer these five questions:

### 1. Contract Alignment
**Question:** Does this comply with our client engagement terms?

| Check | Action |
|-------|--------|
| [ ] Reviewed engagement letter/contract | |
| [ ] No scope creep identified | |
| [ ] Within authorized services | |

**If NO:** Flag for manager review. May need client sign-off or engagement amendment.

---

### 2. Timeline Impact
**Question:** Does this affect any deadlines or deliverables?

| Check | Action |
|-------|--------|
| [ ] Reviewed current project timeline | |
| [ ] No deadline conflicts | |
| [ ] Capacity assessed (if timeline changes) | |

**If YES (impacts timeline):** Document the impact. Escalate if deadline at risk.

---

### 3. Approval Required
**Question:** Does this decision need manager/partner sign-off?

| Check | Action |
|-------|--------|
| [ ] Reviewed escalation policy | |
| [ ] Decision level identified | |
| [ ] Appropriate approver notified (if needed) | |

**Escalation Triggers (customize for your firm):**
- Dollar amount threshold: $_______
- Client relationship changes
- Service date/scope modifications
- Anything affecting engagement terms
- Policy exceptions

**If YES:** Route to appropriate approver before proceeding.

---

### 4. Client Communication
**Question:** What needs to be communicated to the client, and by whom?

| Check | Action |
|-------|--------|
| [ ] Client communication needed: Yes / No | |
| [ ] Draft communication prepared | |
| [ ] Appropriate person identified to send | |
| [ ] Timing determined | |

**Communication Templates:**
- Acknowledgment: "We've received your request and are reviewing..."
- Update: "We're working on [X] and expect to complete by..."
- Completion: "This has been completed. Here's what was done..."

---

### 5. Documentation
**Question:** Where does this get logged?

| Check | Action |
|-------|--------|
| [ ] Client file updated | |
| [ ] Project management system updated | |
| [ ] Workflow calendar updated (if applicable) | |
| [ ] Notes added for future reference | |

**Documentation Locations (customize):**
- Client file: _____________
- Project tracker: _____________
- Calendar/scheduling: _____________
- Team communication: _____________

## Customization Guide

### For Your Firm

Replace the generic items with your specifics:

**Escalation Policy:**
- What decisions can staff make independently?
- What requires manager approval?
- What requires partner approval?

**Documentation Standards:**
- Where do client notes go?
- What system tracks projects?
- How do you update calendars?

**Communication Standards:**
- Who sends client communications?
- What's the expected response time?
- What tone/style is expected?

## Implementation Steps

### Week 1: Foundation
1. Review this template with your team
2. Customize the escalation triggers
3. Define your documentation locations
4. Create your quick reference card

### Week 2: Practice
1. Use the checklist on 5 real situations
2. Note where the checklist catches issues
3. Refine based on what you learn

### Week 3: Integrate
1. Build the checklist into your Claude Project
2. Train team on when/how to use it
3. Make it part of standard workflow

## Sample Scenario: Applying the Framework

**Situation:** Client requests changing monthly reporting from 15th to 5th

**Claude's Guidance:** Process the change request following firm procedures

**Verification:**

| Check | Result | Action Needed |
|-------|--------|---------------|
| 1. Contract | Engagement specifies dates | Need client sign-off on amendment |
| 2. Timeline | 5th is tighter | Assess team capacity |
| 3. Approval | Date changes need manager | Route to manager |
| 4. Client Comm | Need to acknowledge | "Reviewing request, confirm by [date]" |
| 5. Document | Client file + calendar | Update both after decision |

**Outcome:** Cannot simply approve. Escalate to manager with analysis.
